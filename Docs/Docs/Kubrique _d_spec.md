# KUBRIQUE Overview

KUBRIQUE is a speculative, educational aerospace framework describing a new 
class of reusable high-speed vehicles built around a cylindrical “can” 
architecture. It is intended for conceptual research, illustration, 
visualisation, and high-level analysis.

## Core Principles

1. Single-body cylindrical structure (“the can”)
2. Annular rotating-detonation collar for air-breathing thrust augmentation
3. Central methalox rocket core
4. Rim-generator for onboard electrical power
5. Reusability as a core design constraint
6. Public-domain philosophy allowing global contributions

## Applications

• Hypersonic freight  
• Rapid sub-orbital transport  
• Atmospheric detonation-engine research  
• Reusable booster concepts  
• Sci-fi worldbuilding & educational aerospace  

KUBRIQUE is intended to be recognisable, expandable, and open.
