# KUBRIQUE Overview

KUBRIQUE is a speculative, educational aerospace framework describing a new 
class of reusable high-speed vehicles built around a cylindrical “can” 
architecture. It is intended for conceptual research, illustration,
visualisation, and high-level analysis.

## Core Principles

1. Single-body cylindrical structure (“the can”)
2. Annular rotating-detonation collar for air-breathing thrust augmentation
3. Central methalox rocket core
4. Rim-generator for onboard electrical power
5. Reusability as a design constraint
6. Public-domain philosophy enabling global contributions

## Architecture Summary

KUBRIQUE vehicles combine:
- a conceptual rotating-detonation collar (annular)
- a central rocket channel
- layered cylindrical load-bearing structures
- simplified thermal protection representations
- an open, modular design framework

## Applications (Conceptual)

• Hypersonic freight  
• Sub-orbital rapid logistics  
• Reusable booster studies  
• Detonation-engine research  
• Sci-fi and worldbuilding  
• Educational aerospace diagrams  

## Open-Source Intent

All layouts and descriptions in this repository are released into the 
public domain for creative, scientific, artistic, and educational use.

KUBRIQUE is intended to be recognisable, expandable, and open.
